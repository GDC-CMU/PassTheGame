## Notes

- All images should be PNG with an alpha channel when transparency is needed.
- Most plant phases are 64 x 96. Apple phases use custom `sprite_w` and `sprite_h` from `plants.py`.
- Tool icons are optional. Missing icons fall back to text placeholders.
- Scarecrows placed on the field are drawn by the game; only the panel icon is a file.
- `squirrel.png` is intentionally absent from the current folder. The Squirrel thief has a drawn fallback.
- Keep this table in sync with the actual files in `props/`.
